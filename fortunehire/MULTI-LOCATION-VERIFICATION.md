# Multiple-location filtering

Every listed physical state matches on-site, hybrid, and unresolved postings; every employer-eligible remote state matches state-restricted remote postings. Each requisition appears once per result list. Office addresses do not imply remote eligibility.

Remote location parsing now includes city/metro labels ending in ` - Remote`, `Remote-TX`, and `Work at Home`. Existing declared eligibility is preserved. Nationwide remote roles remain nationwide. Local restrictions remain in the employer location wording.

The disclosed city/state on-site policy also runs over retained records at publication, including when employer checks fail. It does not renew check dates or change employer evidence, posting dates, employment type, or locations. Explicit work arrangements and flagged ambiguous settings take priority. Home and remote placeholders cannot become physical offices.

November 17 migration: 58 retained postings classified on-site (8 with multiple locations); 34 remote postings gained missing eligible states. 159 Python tests and 39 browser-filter/data tests pass; 2,862 retained records validate. RTX remains paused.
